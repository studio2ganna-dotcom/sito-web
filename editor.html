Editor sito — modifica testi, font e piccoli spostamenti, poi salva su GitHub

Inserisci i dati del repository e premi "Carica sito".

Come funziona

1. Inserisci utente, nome del repository e (se serve) il branch — di solito main.

2. Premi Carica sito: vedrai l'anteprima esatta del tuo sito qui.

3. Clicca su qualsiasi testo per modificarlo, cambiare font, dimensione, colore o spostarlo leggermente.

4. Premi Salva a destra per scaricare il file o pubblicarlo direttamente su GitHub.

Selezione

Nessun elemento selezionato. Clicca su un testo nell'anteprima.

Salva

Per pubblicare serve un token GitHub con permesso di scrittura sul repository.

Come creare il token

Vai su github.com/settings/tokens → "Fine-grained tokens" → "Generate new token". Seleziona il repository sito-web, e in "Repository permissions" imposta Contents: Read and write. Copia il token e incollalo qui sopra (non viene salvato, resta solo nel browser finché questa pagina è aperta).

Note

Gli spostamenti sono piccoli scorrimenti (nudge), non un drag libero: evitano di rompere il sito su telefono.

Per cambiare foto o video continua a caricarli nella cartella media/ del repository con lo stesso nome file, come hai già fatto.
